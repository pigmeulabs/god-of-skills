# /drawio

Create, edit, validate, preview, or export draw.io diagrams using pigmeu-drawio.

## Usage

```bash
/drawio "model the checkout process" --type bpmn --format png
/drawio "create a mobile login wireframe" --type wireframe
```

## Behavior

Load pigmeu-drawio, classify the diagram, create a plan, generate `.drawio`, validate XML, check layout, export or generate a fallback URL.
