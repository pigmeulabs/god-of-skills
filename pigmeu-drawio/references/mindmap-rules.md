# Mind Map Rules

Use mind maps for brainstorming, scope organization, requirements discovery, study notes, product planning, and content strategy.

## Structure

- One central topic.
- 4-8 primary branches.
- Short labels, usually 1-4 words.
- Sub-branches should be parallel in grammar and granularity.
- Use color by branch, not by every node.

## Layout

- Radial layout for ideation.
- Left-right tree for requirements or plans.
- Top-down tree for hierarchical decomposition.

## Quality checks

- No branch should dominate the diagram unless intentionally detailed.
- Avoid sentences in nodes.
- Keep similar topics grouped under one branch.
