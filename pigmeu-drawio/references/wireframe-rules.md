# Wireframe Rules

Use wireframes for low-fidelity or medium-fidelity UI structure. Do not over-style. Communicate layout, hierarchy, interaction, and content placement.

## Components

Represent common UI elements with simple shapes:

- Header and navigation bars.
- Sidebar.
- Cards.
- Buttons.
- Inputs and selects.
- Tables.
- Lists.
- Modals.
- Tabs.
- Chart placeholders.
- Image placeholders.
- Empty, loading, error, and success states.

## Fidelity

- Use grayscale by default.
- Use minimal accent color only for selected states or primary CTA.
- Avoid decorative icons unless they clarify function.
- Use labels like `Chart`, `Table`, `Hero image`, or `Search input` inside placeholders.

## Layout

- Use consistent grid spacing.
- Align edges and baselines.
- Keep interactive controls large enough to be recognizable.
- For mobile, use common viewport proportions and stack content vertically.
- For web dashboards, distinguish global navigation, filters, content, and actions.
